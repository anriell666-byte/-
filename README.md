# Кликер (нативное приложение)

## Первый запуск на телефоне
1. Установите APK, откройте приложение.
2. Нажмите «1. Показ поверх других окон» и разрешите.
3. Нажмите «2. Служба специальных возможностей», включите «Кликер».
4. Нажмите «3. Запустить бота», разрешите захват экрана.
5. Появится панель: ▶ запуск, ❚❚ пауза, ■ стоп, ● Запись.

## Запись своих нажатий
1. Выберите режим (кнопка «Режим»).
2. Нажмите «● Запись», пройдите этап сами. Выбор отряда не записывайте.
3. Нажмите «■ Сохранить». Запись сохраняется отдельно для режима и разрешения экрана.
4. ▶ — бот повторит записанный путь и сам выберет отряд.

## Журнал
Файл `log.txt` в папке приложения: `Android/data/com.team.clicker/files/log.txt`.

## Сборка на GitHub
1. Создайте репозиторий и загрузите содержимое архива (включая папку `.github`).
2. Settings → Secrets and variables → Actions → New repository secret:
   - `KEYSTORE_B64` — base64 от `clicker-release.jks` (`base64 -w0 clicker-release.jks`);
   - `KEYSTORE_PASSWORD`, `KEY_PASSWORD` — пароли ключа;
   - `KEY_ALIAS` = `clicker`.
3. Перейдите во вкладку Actions → Build APK. Готовый APK появится в разделе Artifacts запуска.
